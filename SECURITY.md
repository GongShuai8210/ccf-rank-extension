# Security policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, open a minimal issue requesting a private contact channel without including sensitive details.

The extension intentionally has no backend, no remotely hosted code, and no general-purpose host permission. Security changes should preserve those constraints.
